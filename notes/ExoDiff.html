ExoDiff

Where does exoplanet data disagree?

2026-10-24

I've been wanting to spend more time working with space data, pipelines and everything related for a little while now. Exoplanets seemed like a good excuse to do that, especially considering the amount of public data available.

While learning and reading, I eventually ended up building ExoDiff.

It pulls catalogue data from public sources, including published measurements and estimates with references to the papers they came from. It compares related values and flags the places where things don't quite add up. The data come from the NASA Exoplanet Archive, NASA's public Exoplanet Catalog, exoplanet.eu and Gaia DR3, with SIMBAD helping match star names between catalogues.

A daily job checks the sources for changes and refreshes the dataset when needed. If a source is unavailable, the pipeline can fall back to a saved copy.

Different doesn't necessarily mean wrong. Values can come from different papers, use different assumptions or be calculated in different ways. ExoDiff runs checks and tests possible explanations, leaving the cases that may be worth a closer look.

Claude Opus 5.5 helped me build it, but the data processing and comparisons are performed by ordinary code. The checks have limitations, and I'm still refining the methodology as I find things that need fixing.

It's live now. If you work with exoplanet data or astronomical catalogues and spot something I've missed, I'd be very interested in your feedback.

The project is open source, and the code is on GitHub.
